## ✨ Key Features
* **🤖 Real-Time AI Detection:** Instantly scans and blocks inappropriate content on screen, including locally saved videos, without needing an internet connection.
* **🔒 Password-Protected Uninstall:** Cannot be uninstalled or force-stopped without entering the master administrator password.
* **⏳ Strict Temporary Device Lock:** Automatically locks the device for a set cooldown period if restricted content is triggered.
* **🛡️ Post-Lock Password Security:** Even after the lock timer ends, the phone remains inaccessible until the master password is entered.
* **🔐 100% Private:** All AI processing happens locally on your phone. No screen data or personal info is ever sent to any server.

2. Download the `.tflite` file from the **[Releases](https://github.com/ahsanpcin/[sheild-lenz]/releases)** section.
3. Open the apk on your Android device and allow **Install from Unknown Sources** if prompted.
4. Open the app and set a strong **Master Password** (make sure to save a backup)
5. Open the app and set a .tflite file from Downloaded **[Releases](https://github.com/ahsanpcin/[sheild-lenz]/releases)**   .
