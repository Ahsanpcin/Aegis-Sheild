## ✨ Key Features
* **🤖 Real-Time Offline AI Detection:** Instantly scans and blocks inappropriate content on screen, including locally saved videos, without needing an internet connection.
* **🔒 Password-Protected Uninstall:** Cannot be uninstalled or force-stopped without entering the master administrator password.
* **⏳ Strict Temporary Device Lock:** Automatically locks the device for a set cooldown period if restricted content is triggered.
* **🛡️ Post-Lock Password Security:** Even after the lock timer ends, the phone remains inaccessible until the master password is entered.
* **🔐 100% Private:** All AI processing happens locally on your phone. No screen data or personal info is ever sent to any server.

## ⚙️ How to Install & Setup
1. Download the `.apk` file from the **[Releases](https://github.com[Aapka-Username]/[Repo-Ka-Naam]/releases)** section.
2. Open the file on your Android device and allow **Install from Unknown Sources** if prompted.
3. Open the app and set a strong **Master Password** (make sure to save a backup).
4. Grant **Device Administrator** and **Accessibility Service** permissions so the anti-uninstall and screen-lock features work properly.

---

## ⚠️ Important Warning
Please remember your **Master Password**. Because this app uses strict Device Administrator locks to prevent bypassing, forgetting your password may lock you out of your device.
